# Aufträge

| Ordner | Bedeutung |
|---|---|
| `offen/` | Neu, noch nicht begonnen |
| `in-arbeit/` | Wird gerade bearbeitet (lokal oder Cloud) |
| `erledigt/` | Fertig, mit Ergebnis |

Neuer Auftrag: `scripts/neuer-auftrag.sh "Titel" "Beschreibung"` – oder einfach Claude sagen „leg einen Auftrag an: …“.
Feld `ort:` → `egal` | `lokal` (braucht den Mac) | `cloud`.
