# Bewerbung – Vertrieb Raum Bremen

**Ziel:** Vertriebsstelle mit **Festgehalt + Provision** in Bremen und umzu
(Delmenhorst, Oldenburg, Achim, Verden, Osterholz, Stuhr, Weyhe, Lilienthal, Bremerhaven).

| Ordner | Inhalt |
|---|---|
| `lebenslauf/` | Stammdaten + Lebenslauf (Master + je Stelle angepasst) |
| `anschreiben/` | Anschreiben je Stelle (`JJJJ-MM-TT-firma.md`) |
| `stellen/` | `jobliste.md` (Recherche), `tracker.csv` (Status je Bewerbung) |
| `unterlagen/` | Zeugnisse, Zertifikate – **erst hochladen, wenn das Repo privat ist!** |
| `vorlagen/` | Layouts / DIN-5008-Vorlagen |
| `versendet/` | Final versendete PDFs |
| `skills.md` | Geprüfte Claude-Skills für Lebenslauf/Anschreiben |

> ⚠️ Das Repo ist aktuell **öffentlich**. Persönliche Daten (Adresse, Telefon, Zeugnisse) erst committen, wenn es auf *Private* gestellt ist.
